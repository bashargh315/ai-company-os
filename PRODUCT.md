# Product blueprint

## Two interfaces
### Client
- Social sign-in: Google, Facebook, X
- Optional passwordless email/phone later
- Minimal onboarding
- Natural-language conversation
- Suggested questions generated from industry + user message
- Company Brain created progressively
- Goal → plan → execution → result
- AI-selected tools hidden behind a simple experience
- Creative studio for professional images/video
- Multilingual and style/dialect adaptive

### Owner / Manager
- PWA installable on phone/desktop
- Customer health and MRR/ARR view
- Agent activity
- Approvals for sensitive actions
- Customer management
- Revenue/subscriptions
- Payment/payout settings
- Bank account placeholder + provider connection
- Audit/security logs
- System configuration

## Agents
CEO, Research, Sales, Marketing, Content, Creative Image, Creative Video, Support, Operations, Analytics, Finance, QA/Security.

## Safeguards
- Agents cannot perform high-risk external actions without permission gates.
- Sales outreach obeys platform rules and anti-spam requirements.
- Financial/legal actions remain advisory unless explicitly approved.
- No credentials, bank details, API secrets, or identity data are stored in the client UI.
